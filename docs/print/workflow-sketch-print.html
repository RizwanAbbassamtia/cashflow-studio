Section 1

The whole system on one page

Each editor runs the app on their own laptop. Channel data is shared through a synced Google Drive folder; media stays local; code and updates come from GitHub. Every video flows through eight stages, and every step between stages is a gate where a person can act.

gate between stages: auto · review · manual data flow service or store outside the app

Section 3

One-time setup per channel

The Channel Setup form collects everything needed to start work. It is saved as one file per channel in the shared folder, so every teammate's app sees the same channel.

Channel

  • Name, YouTube URL (the app resolves the channel id)
  • Main language, optional secondary languages
  • Niche in one line, audience in one line
  • Formats: long-form, Shorts, or both; target lengths
  • Videos per week (used for batch planning)
  • Export folder, music folder, brand colours, caption style
  • Owner, browser profile number for upload, status

Competitors

  • One row per channel: name, URL
  • Priority: main, secondary, watch only
  • Why we track it (free text)
  • Filled by the app: channel id, videos found, last scanned

Frameworks

  • Type: title, long-form script, Shorts script, scene prompt, thumbnail, SEO, style guide
  • Uploaded file (PDF, TXT, MD) or link, version, which format it applies to
  • The script stage reads the whole framework text into its instructions

Voice

  • Tool (ai33), clone link or voice id, voice name
  • Language, model or quality setting, speed, style notes
  • Sample recording path, whether the tool returns word timings
  • Name of the key variable, monthly budget in characters
  • Consent record: whose voice, when and how consent was given

Images

  • Tool (Google), model, style guide sentence added to every prompt
  • Negative rules the quality check rejects
  • Aspect ratios for long-form and Shorts, output resolution
  • Reference images folder (style sheet), popup text style
  • Name of the key variable, monthly budget in images

Thumbnail

  • One to three competitor videos whose thumbnail layout is the template
  • Headline font, colours, maximum headline words
  • Face, no face, or AI character; must include; must avoid
  • Output sizes for long-form and Shorts

Stage modes

  • For each of the eight stages: auto, review or manual
  • Reviewer name per stage
  • Defaults: everything on review except Voice on auto
  • Can be overridden per video when it is created

Settings (per laptop, not per channel)

  • Shared folder path, projects folder, exports folder
  • API keys for Claude, Google, ai33: stored only on that laptop
  • Doctor: checks FFmpeg, yt-dlp, fonts, WebView2, folders, keys, disk space

One video, stage by stage

Read top to bottom. The left column is the service each stage calls; the right column is the human option at that stage. Each gate is set per channel to auto (continue), review (wait for approval) or manual (a person supplies the file).

Section 5

Stage specifications

Each card is one stage: what goes in, exactly what the app does, what comes out, what is checked, and what a person may do. Times are estimates for a ten-minute video on a laptop without a GPU.

01Research

Input
Competitor list from the channel; optional topic typed by the editor
Steps
List each competitor's videos and Shorts tabs without downloading media; cache results; compute an outlier score per video = views divided by the median views of the neighbouring videos of that channel, age-normalised, plus views per subscriber; fetch exact numbers for the top 20 to 50; for the chosen video, fetch the transcript (for structure only, never copied) and the full-size thumbnail
Output
candidates.json · transcript.json · competitor_thumbnail.jpg
Checks
Candidate newer than 7 days is excluded from baselines; channel not scanned more than once per hour; back-off when YouTube asks for sign-in
Human
Pick a candidate, type your own topic, exclude a channel, rescan
Time
1 to 3 minutes

02Title

Input
Chosen candidate title and its metrics; the channel's title framework; the niche and audience lines
Steps
Claude writes 7 variants that keep the proven keywords and structure but are not copies; each gets formula, emotional trigger, curiosity trigger, viral score and a reason it could outperform; a similarity check rejects near-copies of the competitor and of the channel's recent titles
Output
title.json
Checks
Length under 70 characters, no misleading promise the script cannot keep (re-checked after the script exists)
Human
Edit, choose, reorder, ask for 7 more
Time
Under a minute

03Script

Input
Approved title; script framework (long-form or Shorts); target language; target length; transcript summary of the competitor video
Steps
Claude writes the script in sections (hook, setup, progression, payoff, call to action as the framework defines) with sentence boundaries marked; a speech-normalisation pass expands numbers, dates and currency in the target language so the voice reads them correctly; word count set from the target length and the voice's speaking rate
Output
script.md (readable) · script.json (sections and sentences)
Checks
Originality: n-gram and meaning similarity against the competitor transcript and the channel's last 30 scripts must stay under the ceiling; no advisory persona on finance, health or legal topics; title promise appears in the first 20 percent
Human
Edit any paragraph, regenerate one section, lock paragraphs so regeneration never touches them
Time
2 to 5 minutes plus reading

04Storyboard

Input
Approved script sentences; channel style guide; popup style; aspect ratio
Steps
Claude groups sentences into scenes (about 8 to 12 seconds each for long-form, 3 to 4 for Shorts); for each scene writes a text-free image prompt in the channel style, chooses the popup phrase (at most 6 words paraphrasing the narration), a motion preset (zoom in, zoom out, pan, hold) and the transition into the next scene; motion alternates so no two neighbouring scenes move the same way
Output
storyboard.json
Checks
Scene density within limits; at least a set share of scenes carry a popup, chart card or text card; no two prompts near-identical
Human
Edit any field, split or merge scenes, reorder, lock a scene
Time
1 to 2 minutes plus review

05Voice

Input
Approved script sentences; the channel's cloned voice (ai33), speed and style settings
Steps
Synthesise sentence by sentence (small requests, exact sentence boundaries, cheap re-dos); concatenate with sample-accurate offsets; collect word timings from the tool when it returns them; otherwise align in the background on the CPU (several minutes) or fall back to sentence timing; cache every sentence by a content hash so an edit re-bills only the changed sentence
Output
voice.wav (48 kHz) · timing.json
Checks
Words shorter than 40 ms or longer than 2 s are flagged; total duration against target length; consent record present for the voice
Human
Upload your own recording (aligned automatically), re-record a sentence, nudge a timing
Time
1 to 3 minutes

06Images

Input
Storyboard prompts; style sheet image; aspect ratio; negative rules
Steps
Generate one image per scene at the largest size the model offers, passing the style sheet and the previous scene as references for a consistent look; Claude vision checks each image against its prompt (subject present, no garbled text, no real person, no logo, no deformed hands); failures are regenerated up to three times with the reason added to the prompt; a perceptual hash is compared against the channel's past images to prevent reuse
Output
scene_01.png … scene_NN.png · rejected/ · style_sheet.png
Checks
Quality check verdict stored per image; budget guard warns before a batch exceeds the monthly plan
Human
Regenerate with a note, upload an image (for example one made in Flow), lock an image
Time
5 to 10 minutes for 40 scenes

07Edit

Input
Storyboard, voice timing, images, music folder, caption style, brand colours
Steps
Build the timeline: scene in and out from sentence timestamps; zoom and pan path per scene; chosen transition at each boundary; popups rendered as image layers with the brand font; word-level captions as a subtitle track; music under the voice with automatic ducking; render a low-resolution proxy for preview; render the final presets
Output
timeline.json · captions.ass · popups/ · proxy.mp4 · final_720p.mp4 · final_1080p.mp4 · final_2160p.mp4
Checks
Audio peaks, caption readability per language, no black frames, duration equals voice length plus intro and outro
Human
Fix in the built-in editor; or export the project to Kdenlive, DaVinci Resolve or CapCut and import the finished file
Time
5 to 15 minutes per preset on a laptop

08Export

Input
Final renders; approved title; script; competitor thumbnail template; channel brand settings
Steps
Thumbnail: a vision pass extracts the competitor layout (subject position, text blocks, colours, shapes) as a template; the image model draws a text-free subject; the app composes headline and shapes on top in the brand font; SEO pack: Claude writes title, description, tags, chapters and the pinned comment in the target language; disclosure flag set to yes by default; provenance bundle assembled; everything copied to the channel's export folder
Output
thumbnail.png · metadata.json · provenance.pdf · export folder
Checks
Thumbnail similarity to the competitor's below the ceiling; title and thumbnail promise found in the script; music licence stored
Human
Approve, edit metadata, swap thumbnail variant, re-export
Time
1 to 2 minutes

Section 7

Voice timing drives the edit

The voice carries word and sentence timestamps. Those timestamps set where each scene starts and ends, how long each image stays, when a popup appears, when captions change and when the music ducks. This is what makes the automatic edit look cut to the narration instead of to a fixed clock.

How transitions are chosen

Claude assigns a transition to every cut from FFmpeg's library (crossfade, wipes, slides, circle and radial reveals, zoom-through and about forty more). Three rules keep them smooth: the direction of motion carries across the cut (a zoom in is followed by a scene that starts tight and pans, not by a sudden zoom out), the same transition is never used twice in a row, and the duration is matched to the pause in the narration at that point (short cuts on fast passages, half-second fades on calm ones). Shorts use faster, simpler transitions than long-form.

Section 8

Quality gates

YouTube's July 2025 "inauthentic content" rule and its July 2026 clarification describe the output of a careless slideshow pipeline almost word for word. These gates turn that wording into checks the app runs itself. A failed gate blocks export until a reviewer overrides it with a logged reason.

Section 9

Three ways a video is finished

The timeline file is the single source of truth. FFmpeg renders it automatically. For manual fixes the built-in editor changes the same file. For deeper work the project is exported to a professional editor and the finished file comes back.

Section 12

Team setup, data and updates

No one on the team needs git or a developer tool. The installer comes from GitHub Releases and updates itself. Channel data syncs through a shared Google Drive folder. Each person uses their own API keys, stored only on their laptop.

Installing and updating

  • One setup file per release, downloaded from GitHub Releases, with a checksum the app verifies before installing.
  • The app checks for updates at launch and every hour; "Update now" installs and reopens the app. A bad release can be withdrawn so no one is offered it.
  • FFmpeg, yt-dlp, the JavaScript runtime it needs, and all fonts are inside the install; nothing else to install by hand. The Windows web view is installed by the setup file if missing.
  • The Doctor screen shows, on every laptop, what is present, what is missing, and how to fix it.

Section 14

Keys, privacy and safety

  • API keys are typed once into the Settings screen and stored only on that laptop. They are shown masked, never written to the shared folder, never included in logs or exports.
  • The app's local service listens only on the laptop itself; nothing is reachable from the network.
  • Channel files name the key variable to use, never the key.
  • Only the team's own enrolled voices can be cloned; the consent record travels with the voice.
  • YouTube access is read-only (titles, counts, dates, transcripts, thumbnails); no video is downloaded.
  • Every review decision and override is logged with who, when and why, and exported in the provenance bundle for appeals.
  • Spending guards: per-channel monthly budgets for voice characters and images, and a running cost per video shown on the dashboard.
Section 15

Review queue and batch runs

Every stage set to review drops its result into the Review queue with a preview, the checks that ran, and three buttons: approve, edit, redo with a note. Reviewers see one queue across all channels, filtered by channel, stage and age. A batch run creates several videos at once (for example five topics for next week); each video advances on its own until it reaches a review gate, so an overnight run leaves a queue of storyboards ready to approve in the morning. Stage modes can be relaxed to auto per channel once the team trusts the output, and tightened again at any time.

Section 17

A single video as the editor sees it

  1. Open the app, pick the channel. The channel already knows its competitors, frameworks, voice and image settings from the one-time setup.
  2. Click New video. Research runs and shows a ranked list of competitor videos that outperformed their channel, with the outlier score, age and a thumbnail. Pick one, or type a topic.
  3. Seven title variants appear with scores and reasons. Choose one or edit it. approve.
  4. The script appears in the editor with sections and the originality check result. Read it, fix anything, lock the parts you like. approve.
  5. The storyboard board shows every scene as a card: narration, image prompt, popup text, motion, transition. Change what you want, split or merge scenes. approve.
  6. Voice and images generate in the background. Images that fail the quality check are regenerated automatically; the board fills with thumbnails as they arrive. Replace or lock any image. approve.
  7. A low-resolution preview plays with captions and music. If a cut is wrong, open the timeline editor and fix it, or export the project to your own editor.
  8. Final renders (720p, 1080p, 4K) land in the export folder with the thumbnail, the SEO pack and the provenance bundle. approve, then upload.
